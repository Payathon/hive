# hive 前端风格实验记录

> 每一轮：固定一屏和一组假数据，只换风格，对比后在这里写结论。页面放在 `lab/`，直接用浏览器打开即可。

## 第 1 轮：订单详情（2026-10-15）

页面：`lab/01-order-detail.html`

| 方向 | 参照 | 想法 |
|---|---|---|
| A | 闲鱼 / 支付宝 | 黄色状态头、白卡片、底部大按钮 |
| B | Linear / Stripe | 黑白灰、等宽字、动态日志 |
| C | iOS 原生 | 大标题、分组列表、毛玻璃底栏 |
| E | ChatGPT / Perplexity | agent 视角的任务流，付款是对话里的确认卡 |

评判问题：哪一版最让人放心点付款？不看文字能否知道卡在哪一步、在等谁？哪一版最像 hive 自己？

结论：**选 A（闲鱼 / 支付宝式）**。理由：国内用户最容易接受。以后每一轮的评判标准都是：国内普通用户第一次看到，会不会觉得陌生？

- 保留：A 的整体框架，包括状态头、白卡片、横向进度条、底部按钮栏和"确认收货"这类国内用户熟悉的说法
- 淘汰：B、C、E 作为整体方向
- 风险：A 容易变成闲鱼的复刻。下一轮要给 hive 找自己的品牌色，并想清楚 agent 身份怎么表达
- 下一轮：在 A 的框架内试品牌色和 agent 标识；把 A 扩展到市场首页和接单台

## 第 2 轮：品牌色与 AI 身份（2026-10-15）

页面：`lab/02-brand-agent.html`。框架沿用 A；价格红和支付宝蓝付款按钮不动。

- 品牌色：闲鱼黄（对照）、蜂蜜琥珀、活力橙、支付宝蓝
- AI 怎么出现：提示横条（第 1 轮做法）、代付请求（参照淘宝"找人代付"）、六边形头像（AI 六边形 + "AI"角标，人用圆形）
- 用词：把"agent"换成了"AI 助手"，并给它起了名字"小蜂"，更贴近国内用户的说法

结论：

- 品牌色：**支付宝蓝**。和付款按钮同色，最像正规支付。主色和付款按钮都是蓝色后，付款按钮靠位置和大小突出
- AI 身份：**提示横条**，订单顶部一张卡片写"由你的 agent 发起"。不用代付请求和六边形头像
- 用词：**保留"agent"**，不改成"AI 助手"，也不给它起名字
- 下一轮：用蓝色 + 横条，把市场首页和接单台做出来

## 第 2.5 轮：订单页三选一（2026-10-15）

页面：`lab/03-blue-compare.html`。三版都用支付宝蓝、"由你的 agent 发起"横条、界面用"agent"，只比骨架：

- 闲鱼式：渐变状态头、横向进度点、圆角按钮
- iOS 式：大标题、进度环、竖排进度列表、毛玻璃底栏
- 支付宝账单式：居中大金额加状态、竖排时间线、左右对齐明细行、底部通栏按钮

结论：**选支付宝账单式**。顶部居中大金额加状态，竖排时间线，左右对齐的明细行，底部一个通栏主按钮。之后的页面都按这个骨架做。

## 第 3 轮：市场与接单台（2026-10-15）

页面：`lab/04-market-dispatch.html`。不再比风格，看定下的支付宝账单式放到别的页面上是否成立。

- 市场首页：参照支付宝首页，搜索框、宫格入口、待付款提醒、可展开卖家的能力列表；卖家标 agent / 真人
- 接单台：参照滴滴司机端"出车"，圆形大开关、今日数据、派单从底部弹出带 3 分钟倒计时环，抢单 → 等付款 → 拍照 → 交付
- 底部四个标签：市场 / 订单 / 接单 / 我的

结论：**通过**。支付宝账单式在市场首页和接单台上都成立，圆形接单开关和底部弹出的派单卡片保留。

## 第 4 轮：把 app 做成模板的样子，加电脑版（2026-10-21）

起因：用户看了真机，觉得手机上"丑死了"，而且电脑上也得能用、能看。不换方向：支付宝账单式本来就是闲鱼和 iOS 的结合（第 2.5 轮），问题是 app 走样了，没照着 `lab/03` 和 `lab/04` 做。这一轮让 app 对齐模板，并把电脑版当成正式设计来做。

手机（照 lab/03 P、lab/04）：

- 订单页：白色导航栏，居中的类目图标、大金额和状态，竖排时间线，"订单信息"左右对齐明细行，底部毛玻璃操作栏里放一个通栏主按钮（胶囊形）
- 市场：搜索框、待付款提醒（橙色卡）、8 格常用类目宫格、类目列表，点开就地展开卖家（头像、agent / 真人标、标签 chips、通过率），再点"下单"
- 接单台：圆形接单开关（涟漪收小，不再压住下面的字）、今日数据、进行中、我能接的活；上架新能力收进一个虚线"＋ 上架新能力"按钮，展开是带标签的表单
- 从 iOS 拿的：大标题（往上滚后换成毛玻璃小标题栏）、毛玻璃底部标签栏、分段控件（我买的 / 我卖的）、内缩分隔线的列表、开关、safe-area 和 44px 点击区
- 从闲鱼拿的：灰底白圆角卡片、胶囊大按钮、红色价格、标签 chips
- 补齐的状态：加载骨架屏、带图标的空状态、胶囊 toast、表单输入框（聚焦时蓝框）、交付的拍照 / 选文件区和带缩略图的文件列表、消息列表按类型着色的图标

电脑（≥ 900px）：

- 底部四个标签换成左侧边栏：市场 / 订单 / 接单 / 我的 / 消息（带未读数），底部是当前账号；页面里不再放铃铛
- 内容区居中，最宽 1120px；订单、消息列表收窄到 800px
- 市场：左边类目列表，右边固定的详情面板（起步价、可接单人数、卖家、下单按钮），点哪个类目右边就换成哪个
- 订单详情：左边是金额状态卡、交付内容 / 交付表单、进度；右边是操作面板（付款、确认收货等按钮放最上面）、agent 横条和订单信息。手机上的底部操作栏在电脑上变成这个面板
- 下单：左边表单，右边类目和起步价、下单按钮、"下单之后"三步说明
- 接单台：左边接单开关和今日数据，右边进行中和我能接的活；派单从底部弹出改成屏幕中间的对话框，倒计时环保留
- 我的：左边个人信息和账单，右边通知、给 agent 的规矩、我的 agent
- 欢迎页：左边蓝色品牌区，右边注册表单
- 鼠标悬停有底色反馈，键盘焦点有蓝色描边；320px 宽也没有横向滚动

结论：**手机按模板，电脑用侧边栏加两栏**。以后新页面在电脑上也按"主内容在左、摘要和按钮在右"来排。
